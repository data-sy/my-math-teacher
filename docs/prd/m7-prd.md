| # | 결정 항목 | 확정 | 근거 |
|---|---|---|---|
| P-1 | **주 타깃 유저** | **학생 본인 (중·고등 셀프러너)** | self-report·모바일 퍼스트·MBTI식 적응형 문답이 전부 학생 셀프서비스를 가리킴. 신뢰 톤은 유지하되 게이미피케이션은 절제(UX 방향 1). |

### 0.1 유저플로우/CTA 점검 반영 (2026-07-13, 전환 전문 프로덕트 디자이너 대화 점검)

PRD 초안을 **입구→출구 플로우·CTA** 관점으로 대화 점검해 Top 3 연결고리를 닫음:

- **F-1 (① 로그인 게이트 · #2 CTA 위계 동시 해소) — 결과-시점 reverse gate + 게이트 선.** 진단은 비로그인 완주. **무료 = 진단 그 자체**(헤드라인 요약 + 개념 카드[시급도순=순서] + 개념별 **무료 외부자료 링크**) → §5.1의 개념·순서·자료가 **로그인 전 충족**. **게이트 = 독점 자산**(인터랙티브 그래프 학습 경로 + 결과 저장·재열람). 화면 **단일 1차 CTA = "저장하고 학습 경로 시작하기"**(= 로그인 트리거) → 카드별 "학습 경로 보기"는 **2차로 강등**해 #2의 N개 경쟁 제거. *원칙:* 이미 공짜인 공공자료(EBS 등)는 게이트하지 않음(정직성 §2.3; 훗날 유료 콘텐츠 큐레이션 시 별개 판단).
- **F-2 (진척 복구) — 익명 문답 중 localStorage answered-map** 저장 → 이탈해도 재개, 결과-시점 로그인에서 계정 귀속. 서버 주도 stateless 순회와 정합.
- **F-3 (#3 영역 진입) — 스마트 default + ±후보 pick-list.** 학년 기반 시기 추정 단원을 **소프트 default**(hard auto-start 아님)로, 선후(계단)순 **±후보 pick-list**(recall→recognition)에서 원탭 선택 + **"여기 없음?" escape**. **escape는 두 갈래 필수:** (a) **다른 단원 직접 선택** + (b) **"모르겠어 → 전체 훑기"**. — (b)가 특정 단원 없는 "그냥 약점 궁금한" 유저(§2.1 후자)를 흡수하므로 escape 안에서 가드2가 되살아나지 않음((a)만이면 억지로 단원을 고르게 됨). 고른 단원 = **시작 프론티어**(경계 아님 — "몰라요→선수지식 drill-down"이 관용 흡수 → 후보 3~4개면 충분). 카피는 "지금 어디쯤이야?"(배울 내용이 아닌 **시작점** 선택). *진도 안 묶인 유저(복습·선행)도 pick-list + escape(b)로 흡수 → 별도 모드 선택 UI는 MVP 비범위(확정).*

- **F-4 (출구 · 홈 입구 · top-N 마감 — 입구→출구 knob 전부 사인오프):**
  - **결과 출구 = 통합 학습 큐(A안):** 단일 1차 CTA가 개념들의 **공유 선수지식을 병합한 하나의 계단**으로(개별 경로 N개 아님). **⚠️ 정렬 제약(spec-01 필수):** 계단이므로 **위상순(선수지식 먼저)이 지배 정렬**, DKT 시급도는 순수 정렬 키가 아니라 **"어느 취약 개념/독립 가지부터 진입하나"의 진입 우선순위**로만(시급도 '상'이 '중'의 상위일 수 있어 순수 시급도순은 "3단 건너뛰고 5단부터"로 계단이 깨짐). 위상정렬+가지 진입순서 구체 = spec-01. *(C안 경로 맵 미리보기 = 백로그.)*
  - **재진입:** 계정에 **(큐 순서 + 항목별 완료여부 + 현재 위치)** 저장 → 공부 후 "이어서: 다음 개념"으로 복귀. 완료 = **유저 self-mark**(앱이 외부 학습을 검증 안 함). 재진입 = 저장 큐 이어가기, **재진단은 별개 액션**. 앱이 학습 홈베이스 → 출구 누수 방지. *(스키마·저장 UI = spec-01/03.)*
  - **홈 입구(A안):** 1차 "무료 진단 시작" **단독 압도**, 지식그래프는 경쟁 버튼이 아닌 **히어로 비주얼(미끼)**, "둘러보기"는 **조용한 텍스트 링크로 강등**. ⑥ 그래프 탐색엔 상시 **"내 약점 진단하기" CTA**(탐색→진단 루프). *(B 저커밋 진입로 = fast-follow 백로그.)*
  - **결과 top-N(A안):** §4.2 등급 컷의 **'상' 개념만 default(3~5로 bound — 외톨이 1장·과부하 동시 방지), 중/하는 "더 보기".** 카드 수 = "네 심각한 약점 개수"라는 의미를 가짐.

## 1. 제품 한 줄 정의

> **"수학은 계단이다. 어디서 막혔는지, 3분 자가진단으로 AI가 짚어준다."**

중·고등 학생이 **문제를 풀지 않고** 개념을 "알아요/몰라요"로 자가응답하면, 지식그래프가 무너진 토대를 적응형으로 추적하고, AI(DKT)가 시급도 순위를 매겨 **무엇을 어떤 순서로 채울지**를 그래프 학습 경로 + 무료 외부 자료로 안내한다.

## 2. 타깃 유저 · 핵심 가치

### 2.1 주 타깃 (P-1)

- **누구:** 중·고등학교 학생 본인(셀프러너). 시험·내신을 앞두고 "내가 어디가 약한지" 스스로 궁금한, 모바일로 진입하는 학생.
- **왜 이들인가:** self-report OX 자가응답은 **개념을 스스로 인지·판단할 수 있는** 사용자에게만 유효하다(초등 저학년은 자가평가 신뢰도 낮음). 무료·저마찰·모바일·MBTI식 흐름은 학생 셀프서비스에 최적.
- **부차 고려(비타깃):** 학부모는 결제·신뢰의 배경 이해관계자이지만 **직접 자가진단하지 않는다.** 신뢰 톤(정직한 프레이밍·완성도)은 학부모 눈높이로 유지하되, 카피·인터랙션은 학생 1인칭으로 설계한다.

### 2.2 핵심 가치 제안

1. **저마찰 진단** — 문제 풀이·저작권 문항 없이 "알아요/몰라요"만으로 3분 내 진단(문제 풀 실부재 우회).
2. **막힌 지점의 뿌리 찾기** — "몰라요" 개념에서 선수지식으로 drill-down, "알아요"는 하위 가지 skip → 짧은 문답으로 **무너진 토대의 바닥**을 특정(지식그래프를 테스트 엔진으로).
3. **"그래서 뭘 하지"까지** — 취약 개념을 시급도순으로 제시하고, **그래프 학습 경로 + 개념별 무료 외부 자료**로 다음 행동을 연결.

### 2.3 포지셔닝 (정직한 "AI 진단")

- **"AI 진단" 간판 유지** — self-report OX 를 정오답(안다=맞음/모른다=틀림)으로 매핑해 기존 DKT(TF Serving)가 시급도를 산출하므로 "AI가 분석" 서사 성립(밀스톤 D3-R).
- **단, 정직하게 병기** — "인증·평가"가 아니라 **"자가진단 학습 가이드"**. 시급도는 절대 점수가 아니라 **상대 우선순위**로 제시(과대주장 회피, R1·R3 완화).

## 3. 제품 루프 · MVP 화면 (P-1/P-2/P-3 반영)

### 3.1 종이 플로우

```
① 홈(가치제안 + "무료 진단 시작" / "개념 그래프 둘러보기")
   → ② 영역 진입 (학교급/단원 선택으로 그래프 진입점 좁히기)
   → ③ 그래프 적응형 문답  ← 화면당 개념 1개, "알아요 / 몰라요"
        · 개념 이름 + 대표 예시(미니 그림/한 줄)   ← 이름만이면 "내용은 아는데 이름을 몰라" 오답(D5)
        · "알아요" → 하위 선수지식 가지 skip
        · "몰라요" → 그 개념의 선수지식으로 drill-down
   → ④ 결과 (헤드라인 요약 → 개념 카드 시급도순 → 각 카드 그래프 경로 + 외부링크)
```

로그인/에러는 횡단 화면. 개념그래프 탐색(⑥)은 진단과 독립적으로 진입 가능한 "서비스의 얼굴".

| # | 화면 | 목적 | 핵심 요구 |
|---|---|---|---|
| ① | **홈** | 가치제안 + 진입 | 헤드라인(§1) + **1차 CTA "무료 진단 시작" 단독 압도**. 지식그래프 = **히어로 비주얼(미끼)**, "둘러보기"는 **조용한 텍스트 링크로 강등**(퍼널 누수 방지) + 작동방식 스텝. UX B-1 각색. → §0.1 F-4. |

| ⑥ | **개념그래프 탐색** | 서비스 해자 | 검색 한 줄 + 그래프 상시 표시(호버 의존 제거, 모바일 동작). **상시 "내 약점 진단하기" CTA**로 탐색→진단 루프. UX B-2 각색. → §0.1 F-4. |

### 3.3 진단 진입 · 로그인 게이트 (F-1 확정)

- **문답은 비로그인으로 완주**(결과-시점 reverse gate) — 홈 "개념 그래프 둘러보기"도 비로그인 허용(현행 유지). "가치 먼저, 계정 나중."
- **무료/게이트 선(§0.1 F-1):** 무료 = 진단 결과(헤드라인 + 개념 카드 시급도순 + 개념별 무료 외부자료 링크). 게이트 = **인터랙티브 그래프 학습 경로 + 결과 저장·재열람**(독점 자산 = peak-value 로그인 보상).
- **진척 복구(§0.1 F-2):** 익명 문답 중 localStorage answered-map 저장 → 재개, 로그인 시 계정 귀속.

## 4. 자가진단 결과를 유저에게 어떻게 권할지 (§113 핵심)

UX 리포트 B-3("헤드라인 요약 → 우선순위 카드 → 근거")를 **self-report 피벗에 맞게 각색**한다. (B-3 원안은 "4·7번 오답" 같은 정오답 근거 전제 → self-report 근거로 치환.)

### 4.1 추천 단위 = 개념 단위 카드 (P-2)

- 취약점을 **개념 단위 카드**로 노출. 카드 1장 = 취약 개념 1개.
- **top-N 확정(F-4):** default = **§4.2 '상' 등급 개념**. **컷 규칙(확정):** '상'<3이면 **'중'에서 시급도순 보충해 바닥 3장**, '상'>5이면 **5장 캡**, 나머지는 **"더 보기"**. (3 바닥=외톨이 1장 방지, 5 캡=모바일 폴드·과부하 방지.) 등급 컷이라 카드 수 = "네 심각한 약점 개수"라는 의미를 가짐. *(spec-01 남는 것 = **무슨 시급도가 '상'인가**의 등급 컷 임계값만 §4.2 — 대화에선 미확정.)*
- 영역(단원) 요약은 **헤드라인 한 줄**에서만 언급("이차방정식 영역에서 3개 약점"), 액션은 개념 카드에 건다.

### 4.2 시급도 우선순위 규칙

- **입력:** self-report OX → **안다=맞음(정답) / 모른다=틀림(오답)** 매핑 → 기존 DKT 입력 시퀀스(`AnswerService.findAIInput`)에 흘려넣음(밀스톤 D3-R).
- **산출:** DKT(TF Serving) `probabilityList` → 개념별 시급도. 카드 정렬·상/중/하 등급의 근거.
- **표현 원칙:** **절대 점수(블랙박스 %)가 아니라 상대 우선순위**로. 각 카드에 "왜 급한가"를 **사람 언어**로 한 줄("이걸 모르면 위로 N개 개념이 막혀요" — 그래프의 blocked-descendants 근거). 내부용어(toConceptDepth, probability_percent) 노출 금지.
- *(가중치·정규화·등급 컷의 구체는 spec-01 기술 설계에서 확정. PRD는 "상대 우선순위·설명가능"까지만 규정.)*

### 4.3 결과 화면에서 유저가 취할 액션 (P-3 · F-1)

- **상단 헤드라인 요약** — 예: "총 12개 개념 중 3개 약점, 가장 급한 건 '인수분해'" + 개요 지표.
- **화면 단일 1차 CTA = "저장하고 학습 경로 시작하기"** — 화면 레벨 THE 1차는 **하나**(#2의 N개 경쟁 제거). 비로그인 시 이 CTA가 로그인 트리거. 게이트 보상 = **인터랙티브 그래프 학습 경로**("무너진 토대 → 목표 개념" 순서를 그래프 위 가이드로, 다운로드 아님·해자) + 결과 영속화.
- **각 개념 카드(무료)** — 진단(무엇이·왜 약한지, 사람 언어 근거) + **무료 외부 학습 링크**(EBS 등, 비로그인 노출; spec-03 데이터) + "학습 경로 보기"는 **2차**(단일 1차 아래 강등).
- **상세(문항별·전체 그래프)** — "근거 더보기"로 접어 강등.
- **출구 = 통합 학습 큐(F-4):** 단일 1차 CTA는 개념들의 **공유 선수지식을 병합한 하나의 계단**으로(개별 경로 N개 아님). **⚠️ 정렬 제약(spec-01 필수):** 계단이라 **위상순(선수지식 먼저)이 지배 정렬**, DKT 시급도는 순수 정렬 키가 아니라 **"어느 취약 개념/독립 가지부터 진입하나"의 진입 우선순위**로만(시급도 '상'이 '중'의 상위일 수 있어 순수 시급도순은 계단이 깨짐). 위상정렬+가지 진입순서 = spec-01. *(C안 경로 맵 미리보기 = 백로그.)*
- **재진입(홈베이스):** 계정에 **(큐 순서 + 항목별 완료여부 + 현재 위치)** 저장 → 공부 후 "이어서: 다음 개념"으로 복귀. 완료 = **유저 self-mark**(앱이 외부 학습을 검증 안 함). 재진입 = 저장 큐 이어가기, **재진단은 별개 액션**. 앱이 학습 홈베이스가 돼 출구 누수 방지. *(스키마·저장 UI = spec-01/03.)*

## 5. 성공 기준

### 5.1 제품 기준 (런치 판정)

- **적응형 동작:** "알아요"가 선수 가지를 실제로 skip 해 문답 화면 수가 유의미하게 준다(전 개념 나열 대비). — 진단이 "짧다"는 체감.
- **결과의 행동가능성:** 결과 화면에서 유저가 "그래서 뭘 하지"의 답(개념·순서·자료)을 **설명 없이** 얻는다(UX 검증). raw 표·내부용어 없음. **개념·순서·자료는 로그인 전(무료)에 충족**(§0.1 F-1) — 로그인 게이트가 §5.1을 막지 않음.
- **모바일 무결:** 홈·문답·결과·그래프 탐색이 모바일 뷰에서 깨지지 않는다(반응형, 사람 시각검증).
- **포지셔닝 정직성:** "AI 진단" 서사가 성립하되 self-report 기반임이 화면에 정직히 병기된다(과대주장 없음).

### 5.2 기술 검증 기준 (밀스톤 §검증 승계)

- self-report OX → 정오답 매핑이 기존 DKT 입력 시퀀스와 정합하고 `probabilityList` 시급도가 나온다(TF Serving 실응답 확인).
- self-report 경로가 실문항·`items` 무의존으로 완주한다.
- 라이브 배포 후 `https://www.my-math-teacher.com` 에서 새 루프가 동작한다.

*(정량 KPI(가입 전환율·완주율 등)는 런치 후 GTM/컨설팅 트랙에서 계측. PRD 단계에선 위 정성·기능 기준을 게이트로.)*

## 6. 비범위 (Out of Scope)

- **부가 화면** — 채점 상세·학습 이력(RecordView)·회원정보 수정(UserEditView)·회원가입 상세 폼: **오픈 후 이식**(밀스톤 D6). MVP 6종에 미포함.
- **학습지 출제·PDF(html2pdf)** — D4로 폐기(그래프 경로 + 외부링크로 대체).
- **LLM 문제 생성** — 품질 보장 불가로 기각(밀스톤 §왜 피벗). self-report 우회 채택.
- **DKT 재학습 / self-report 전용 모델** — 실문항 확보 시 별도 마일스톤. 현재는 기존 모델에 매핑 입력만.
- **`items` 풀 정리·마이그레이션** — self-report 는 `items` 미사용 → 유휴화만, 삭제는 후속.
- **백엔드·인증·인프라·그래프 데이터 변경** — 무변경(프론트만 교체). blue-green·SSM·Terraform·nginx 정적 서빙 그대로.
- **데스크톱 전용 최적화·다크모드** — 모바일 퍼스트 우선, 데스크톱은 반응형 하한만.
- **정량 GTM KPI 계측 파이프라인** — 런치 후 트랙.
- **fast-follow 백로그(오픈 후 이식)** — 결과 **경로 맵 미리보기(C안)**, 홈 **저커밋 진입로(B안)**. MVP는 F-4의 A안들로 가되 이 대안은 후속.

## 7. 리스크 (밀스톤 레지스터 승계, PRD 관점)

- **R1 자기보고 정확도** — 과대평가 학생이 DKT 입력을 오염. 완화: 개념 이름+예시(D5), "자가진단 가이드"로 정직 프레이밍, 상대 우선순위 제시.

- **R4 외부 링크 유지보수** — 상위 개념 소수부터, 점검 주기 필요.
- **R6 진입 진도표 콘텐츠 의존** — 시기→단원 스마트 default(§0.1 F-3)가 학년×시기 표준 진도표에 의존(학교·출판사·선행 편차로 확률적 guess). 완화: default는 **제안(soft)일 뿐**, ±후보 pick + "여기 없음?" escape로 오추정 흡수. R4류 소규모 유지보수 항목, 세부는 spec.
