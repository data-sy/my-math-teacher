1. **클라우드 쪽은 닫혔다.** AWS 계정에 과금 리소스 0 · RDS 스냅샷 0(2026-10-02 실측, 전 리전). 남은 것은 $0 짜리 청구 알람·예산·IAM role 뿐.
2. **프로덕션 데이터는 없다.** 마지막 스냅샷을 지웠다 — 데이터 정본은 `api/sql` 시드 + `shared/data/concept-links-seed.csv`.
   재런치는 "빈 RDS + 시드 적재"이고 **이 경로는 실증된 적이 없다**.
3. **남은 일은 전부 로컬·코드**다(§3). 급한 것은 없다.

## 1. 상태 확인 (read-only · 값은 여기서 얻는다)

```bash
cd ~/my-math-teacher
git branch --show-current              # 다른 세션이 바꿔놨을 수 있다 — 커밋 전에 확인
git log --oneline main..HEAD           # 비어 있지 않으면 미머지 커밋이 있다
git status --short
docker ps --format '{{.Names}}'        # mmt-* 0줄 예상. 남의 스택이 3306/6379 를 잡고 있을 수 있다
docker volume ls | grep -E 'mysql-vol|neo4j-vol'   # 0줄 = 시드 재적재 경로
whois my-math-teacher.com | grep -i expir          # 도메인 만료(2026-10-01 조회값 = 2027-06-17)
```

AWS 를 볼 일이 있으면 `bash .local/mmt-aws-session.sh <MFA 6자리>` (1시간짜리 `mmt-session` 프로파일. gitignore 된 개인 스크립트 — 리포를 다시 클론하면 없다. 내용은 `mmt-base` 프로파일 + MFA 로 `mmt-terraform-admin` 역할을 assume 하는 것뿐이라 다시 쓰기 쉽다).

> ⚠️ **AWS CLI 키는 꺼 뒀다.** `mmt-cli` 액세스 키를 비활성화했으므로(2026-10-02 결정) 위 스크립트가 인증 실패하면
> 콘솔 → IAM → Users → `mmt-cli` → Security credentials → 액세스 키 **Activate** 가 먼저다.
>
> ⚠️ **도메인이 끊겼을 수 있다.** 등록 만료일 2027-06-17. 도메인은 계속 보유할 생각이고 자동갱신일 것으로 기억하지만 타 계정이라 확인한 적은 없다 — 그 날짜 뒤라면 `whois` 부터 본다.
