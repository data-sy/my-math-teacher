## 확정 결정 (2026-07-17 프로토타입 리뷰 — 와이어프레임에 반영할 것)

| 화면 | 결정 |
|---|---|
| ① 홈 | "이어서: 다음 개념" 배너(로그인+활성 큐 시만) 채택. 그래프 = 히어로 비주얼 유지(하이파이에서 재판단) |
| ② 진입 | 카피 "진단하고 싶은 것을 고르세요"(짧게 — 내부 동작 설명 금지). 진행 중 세션 → [이어서 진행/새로 시작] 선택. 새 진단 = 새 세션 |
| ③ 문답 | "‹ 이전 답 수정" = 직전 답 1개 undo만(임의 과거 답 수정 = 인과 불변식 위반 금지) |
| ④ 결과 | 무료→게이트 = 같은 화면 2상태. 게이트 상태 순서 = 그래프 경로 → 진단 카드 → 큐 체크리스트. 더 보기 = 펼침/접기 토글. 게이트 안내문 = 무료 먼저("진단 결과와 자료는 무료예요 — …") |
| ④ 약점 0 | B안: 1차 버튼 "한 계단 위 '단원' 진단하기" + 조용한 링크 "그래프에서 확인하기 ›" (근거: `04-result-empty-variants.html`) |
| 공통 | 화면당 단일 1차 CTA(F-1). 그래프 탐색 진입은 어디서나 조용한 텍스트 링크. 링크 화살표 › / undo ‹ |
