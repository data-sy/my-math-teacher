## 3. ② zdbg 프로덕션 테스트 계정 정리

**정본:** [`../backlog/m7-diagnostic-test-accounts-cleanup.md`](../backlog/m7-diagnostic-test-accounts-cleanup.md)

  `/analyze-before-change` 급은 아니지만 참조 무결성은 확인해야 한다.

## 4. ③ CI 백엔드 이미지가 프로덕션 부팅 불가 — **숨은 지뢰**

**정본:** [`../backlog/ci-backend-image-missing-secure-yml.md`](../backlog/ci-backend-image-missing-secure-yml.md)
· **상태:** 미착수, "제대로 고치기로 결정(2026-07-27 사용자)"

시크릿 유출 대응(`c7f608d`)이 `application-secure.yml` 을 추적 해제하면서 **그 안의 비밀 아닌
env 매핑 구조까지** 사라졌다. 그래서 CI(`api-ci-cd-with-ec2.yml`)가 빌드하는 이미지는
datasource 설정이 없어 프로덕션에서 부팅 실패한다:

```
Failed to configure a DataSource: 'url' attribute is not specified
```

**왜 지금이냐:** ④(M8)이 백엔드 작업이다. 지금 백엔드를 고치면 **배포할 방법이 없다.**
현재 프로덕션 백엔드는 수동 빌드 이미지로 떠 있어서 문제가 가려져 있을 뿐이다.

**주의:** 시크릿을 다시 커밋하는 방향으로 풀지 말 것. 매핑 구조(`${ENV}` 껍데기)와 실제 값의
분리가 핵심이다 — `api/CLAUDE.md` §보안 · [[feedback_public_repo_secret_leak_rotate]] 참조.

## 5. ④ [M8] 개념 학습자료 링크

**설계 정본:** [`../specs/m7/spec-03-learning-path-links.md`](../specs/m7/spec-03-learning-path-links.md)
(2026-07-13 U1~U6 사인오프 완료) · **로드맵:** ROADMAP `[M8]`

**현재 증상:** 결과 카드의 `links` 가 **항상 빈 배열**이다. `concept_links` 테이블이 프로덕션에
없다(`information_schema` 확인 = 0). 카드에 "왜 급한가"만 있고 **"그래서 지금 뭘 보나"가 비어 있다.**

- **프론트는 이미 `links` 를 렌더한다**(`Result.tsx` CardView) — 데이터가 생기면 그대로 나온다.
  남은 것은 **전부 백엔드 + 콘텐츠**다.
- 규모: DB 테이블 + 백엔드 조회 + **사람 손 시드**(병목 상위 30~50 개념 × 링크 3개, 결측 허용).
- 구현 감시 2건(provenance NULL 누수 · nullable+앱 non-null) = spec-03 §6.
- **파생 항목(같은 트랙):** 카드 근거를 숫자 대신 **후수 개념명 지목**으로
  ("'○○'을 배우려면 먼저 필요해요"). 백엔드 DTO 필드 + 대표 후수 선정 쿼리.
  1단계(0개면 숨김)는 2026-08-06 에 프론트에서 처리 완료.

## 8. 환경 (CLAUDE.local.md 정본 — 여기 중복 최소)

```bash
# 인프라
docker compose up -d mmt-mysql mmt-neo4j mmt-redis mmt-ai
# 백엔드 (진단 경로 ON)
cd api && MMT_DIAGNOSIS_ENABLED=true MMT_MIGRATION_USE_MYSQL_CTE_FOR_GRAPH=true \
  MMT_DIAGNOSIS_SERVING_URL=http://localhost:8501/v1/models/my_model:predict ./gradlew bootRun
# 프론트 (mock) / 실서버 모드
cd web-v2 && npm run dev
cd web-v2 && VITE_ENABLE_MOCK=false VITE_API_BASE=http://localhost:8080 npm run dev
# 검증
cd web-v2 && npx tsc --noEmit && npm run lint && npx playwright test   # mock e2e 16종
```

⚠️ 외부 redis 가 6379 를 점유하면 테스트가 그쪽에 붙어 **위장 green** 이 된다 — `lsof -i :6379` 확인.
⚠️ 프론트 이미지는 **`docker buildx build --platform linux/amd64`** 필수(맥 arm64 ≠ EC2 x86_64).
⚠️ 프론트는 **CI 없음** — 수동 빌드. 이미지 repo = `mmt2024`(`mymathteacher` 아님).
