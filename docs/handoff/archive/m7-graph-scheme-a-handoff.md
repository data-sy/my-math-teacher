> 이 문서를 통째로 프론트 v2 개발 세션에 붙여넣는다. 백지 컨설팅(2026-07-18)의 결정 사항을 실행하는 문서다.
> 배경 전문이 필요하면 `../consulting/out/graph-hierarchy-report-2026-07-18.md`, 시각 비교는 `../consulting/out/graph-hierarchy-mockup.html` (참고용 — 이 문서만으로 실행 가능해야 한다).

## 결정

개념 그래프 "노드 탭 시 시각 위계"는 **콘셉트 A — 색 층위**로 확정. hue = 방향(선수/후수), 명도 = 거리(직접/원거리), 좌표·레이아웃 불변. B(공간 재배치)·C(형태·크기)는 탈락 — 단, 사용자 테스트에서 "한 덩어리" 문제가 재현되면 B 승격을 재논의한다.

## 불변 원칙 (팔레트를 바꿔도 유지)

1. **상태 공간은 노드 6 + 엣지 3으로 고정.** 노드: 선택 / 선수-직접 / 선수-원거리(뎁스 −2 이하 병합) / 후수-직접 / 후수-원거리(+2 이하 병합) / 계보 밖. 엣지: 직접(선택 인접) / 계보 내 원거리 / 계보 밖. 뎁스별 색 세분화 금지 — 크기만 뎁스 따라 연속 감소 허용.
2. **방향 = hue 2계열(범주), 거리 = 명도 2스텝(순서).** 명도로 방향을 나누거나 hue로 거리를 나누지 않는다.
3. **난색(빨강·주황·호박) 금지** — 서비스의 경고/시급도 의미와 충돌. 냉색 2계열만.
4. **계보 밖 = 무채색화 + 축소 + 라벨 감쇠.** 숨기거나 투명도로 처리하지 않는다(엣지 겹침에서 지저분).
5. **선택 노드 = 크기 최대 + 명도 극단 + 흰 링 + 할로.** hue를 쓰지 않는다(방향 의미 오염 방지).
6. **엣지 방향은 화살촉 필수**(직접·계보 내), 계보 밖만 생략. 호버 없음 전제.
7. **모션은 선택 전이 1회 200~250ms만.** 지속 애니메이션 금지.
8. **무선택 모드**(탭 전)는 전 노드 중립 단일 톤·균일 크기 — 상태 분화 없음.

## 과제

1. **팔레트 맵핑** — 위 기준 hex를 v2 디자인 시스템 팔레트로 치환하라. 컨설팅은 의도적으로 백지(현 팔레트 미제공)였다. 치환 조건:
   - 냉색 2계열 유지 (v2 팔레트에 냉색 2계열이 없으면: 브랜드 주색 1 + 보조 냉색 1 신설을 제안하고 승인 대기)
   - 치환 후 **CVD 재검증 필수**: 방향 쌍(직접끼리·원거리끼리)의 OKLab CVD ΔE ≥ 8(protan/deutan), 명도 램프는 모노톤·라이트엔드 대비 ≥ 2:1. 눈짐작 금지 — 검증기로 계산.
   - 원거리 톤의 표면 대비 3:1 미만은 의도된 후퇴로 허용하되, 그 릴리프로 라벨이 반드시 붙어야 한다.
2. **설계 정본 갱신** — `docs/design/v2/06-graph.html`에 A안 상태 스펙(맵핑된 값)을 반영. 구 아카이브(`docs/design/m7-*`)는 손대지 않는다.
3. **구현** — 그래프 화면에 적용. Cytoscape 기준 전 속성이 표준 스타일(fill·border-width·width/height·label 폰트)로 구현 가능하다. 선택 시 BFS로 선수/후수 계보를 구해 노드·엣지에 상태 클래스를 부여하는 방식 권장. 라벨 저줌 생략은 `min-zoomed-font-size`.
4. **검증** — 390px 뷰포트에서: 선택 1회 탭으로 ① 토대가 어느 쪽인지 ② 열리는 것이 어느 쪽인지 ③ 직접/간접이 갈리는지 육안 확인 + 줌아웃 상태에서 선택·직접 노드가 여전히 초점인지 확인. 스크린샷을 검수자에게 제시한다.

## 하지 않는 것

- B안 요소(밴드 재배치·거터) 구현 금지. B의 "요약 칩"(토대 N개 · 열리는 길 M개 오버레이) 이식은 별도 백로그 — 이번 범위 아님.
- C안 채움/빈 원 은유 결합 금지(저줌 소실 리스크, 2차 검토 항목).
- 뎁스별 색 세분화, 지속 모션, 난색 사용 금지 (위 불변 원칙).
