# [백로그·방향 검토] 카피/타겟팅 — 페르소나를 고등학생으로 축소, "중학교 지식에서 뭘 모르는지" 프레임

> 등록 2026-07-18 (제로베이스 샌드박스 하이파이 폴리싱 중 사용자 발상) · **결정 대기 — 본 레포에서 고민할 것** (샌드박스에서 즉흥 결정하지 않기로 함)

## 무엇

현재 카피·타깃은 "중·고 수학"을 넓게 잡는다 (홈: "수학은 계단이다. 어느 칸이 비었는지 3분이면 보여요"). 검토할 대안:

- **페르소나 = 고등학생**으로 좁히고,
- 질문 프레임을 **"중학교 지식에서 내가 뭘 모르는지"** 로 축소 — "고등 수학이 막히는 이유는 중등 토대"라는 더 구체적인 훅.

## 왜 검토하나

- 타깃 축소는 카피의 절박도·구체성을 높인다 — "너 지금 고1인데 중2 인수분해가 비어서 막히는 거야"가 "수학 약점 진단"보다 클릭 동기가 강할 수 있음.
- 블라인드 평가(제로베이스 `docs/design/eval-results/blind-s3`)에서도 "틸의 첫인상이 심심해서 클릭 동기는 카피가 만들어야 한다"고 지적 — 카피가 훅의 주역이라는 진단과 정합.
- 단, 역전 조건도 같은 평가에 있음: 타깃을 절박한 고2~고3으로 좁히면 "신뢰·권위"가 병목이 되어 색 선택(틸 vs 블루)의 전제가 흔들릴 수 있음 — 카피·타깃·팔레트가 연동된 결정임.

## 영향 범위 (착수 시 확인)

- 홈 헤드라인·서브카피·히어로 서사, ② 진입의 학년 선택 기본값(고등 우선), ④ 결과 카피 톤.
- 중학생 유저를 배제할지, "고등학생용" 프레임만 앞세우고 기능은 유지할지.
- 팔레트 재검토 트리거 여부(위 역전 조건) — 필요시 블라인드 평가 킷 재사용(제로베이스 `docs/design/🤖-하이파이-BC-블라인드-평가-프롬프트.md` 방식).

## 처리 규칙

- 제로베이스 샌드박스의 카피 폴리싱은 이 결정을 선점하지 않도록 **톤 정리 수준으로 최소화**하고, 카피 확정은 본 백로그 결정 후 본 레포에서.
