# [백로그·결정 대기] ④ 결과 — 완주·미저장 세션의 재프리뷰 진입로를 추가할 것인가

## 상황

문답을 완주(done)했지만 저장(로그인)하지 않은 유저가 ④-A에서 이탈하면 그 결과로 돌아올 진입로가 없다 — ②의 이어가기는 **미완주** 세션만 대상(spec-01 S1-A). **MVP 확정 = (a) 소실 허용:** "저장하고 학습 경로 시작하기" 1차 CTA가 바로 그 해답이고, 소실 가능성이 게이트(저장) 가치를 강화한다.

## 결정할 것 (런치 후 신호 보고)

**(b)안을 추가할 것인가:** 완주 answered-map을 localStorage에 유지하고, 홈에 "결과 다시 보기" 조용한 링크 → `POST /diagnosis/preview` 재호출로 ④-A 재구성(무영속·배선만 추가).

- **추가하는 쪽 근거:** 실수 이탈(뒤로가기·탭 닫힘)로 3분 진단 결과가 날아가는 경험은 가혹 — F-2(진척 복구)의 정신은 완주 후에도 유효할 수 있음.
- **안 하는 쪽 근거:** 소실이 곧 저장 유인(게이트 전환율) — 재프리뷰가 있으면 "로그인 안 해도 되네"가 됨. preview rate limit(10회/분/IP) 소모 경로 추가이기도.
- **판단 신호:** 런치 후 ④-A 도달 대비 저장 전환율·이탈률. 이탈이 크고 전환이 낮으면 (b)가 완화책인지, 오히려 게이트를 더 약화시키는지 따져 결정.
