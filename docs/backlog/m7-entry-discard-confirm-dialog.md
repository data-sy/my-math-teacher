## 무엇

②에서 진행 중(미완주·미저장) 문답 세션의 answered-map을 폐기하는 두 경로에 확인 다이얼로그를 붙인다:

- "새로 시작" 탭 → "진행했던 진단이 초기화됩니다. 삭제하시겠습니까?" [삭제 / 취소]
- 진행 중 세션이 있는 상태에서 **다른 단원 원탭** → 동일 확인(기존 진행분 자동 폐기 전에)

## 왜 지금 안 하나 (2026-07-17 검수 확정)

- 순수 **추가 배선** — 폐기 호출 앞에 모달 한 겹. 데이터 모델·API·화면 전이 무영향이라 MVP 완성 후 리팩토링으로 붙여도 안전.
- MVP·테스트 환경에선 확인탭이 없는 쪽이 반복 시나리오 수행에 유리(진단 재시작을 빈번히 함).
- 완화 장치는 이미 있음: ●4 노트에 단원명·답변 수 표기(무엇이 날아가는지 보임) + 폐기 대상이 익명 localStorage 세션뿐(저장된 큐·계정 데이터는 무관).

## 착수 시 할 일

- 확인 카피 학생 친화 톤 통일(⑤-B 에러 카피 규약과 정합).
- "다른 단원 원탭" 경로는 확인 후 진행 시 원탭-즉시-시작(②의 확정 인터랙션)이 한 홉 늘어나는 것이므로, 진행 중 세션이 있을 때만 조건부로 모달이 뜨는지 테스트로 보장.
