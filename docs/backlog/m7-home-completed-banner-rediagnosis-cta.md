# [백로그] 홈 완료 배너 → 재진단 직행 CTA (결정 2의 B안)

> 등록 2026-07-17 · 출처 = ① 홈 와이어프레임 검수(`docs/design/v2/01-home-variants.html` 결정 2) · **비차단 — MVP는 A안으로 확정**

## 무엇

로그인 유저가 학습 큐 전 항목을 완료한 상태의 홈 재진입 배너:

- **MVP 확정(A안):** "학습 계단 전부 완료 🎉 ›" 문구만 대체, 탭은 보통 상태와 동일하게 ④-B(큐 재열람). 재진단은 ④-B 안의 별개 액션.
- **본 백로그(B안):** 완료 상태의 배너 탭을 ② 영역 진입(재진단)으로 직행시켜, "공부한 만큼 올라갔는지 확인" 서사로 제품 루프를 재점화.

## 왜 보류했나 (2026-07-17 검수 판단)

- B안은 진단이 **as-is → to-be 의 to-be 측정** 역할을 할 때 자연스럽다. 그러나 현재 진단은 **self-report 자가응답**이라 "공부 후 재측정" 서사가 객관적 상승 확인으로 성립하지 않음(자가 채점의 한계) — 서사가 서기 전에 직행 CTA를 걸면 과대주장 리스크(PRD §2.3 정직성)와 충돌.
- 부수 비용: 같은 배너가 상태에 따라 다른 화면(④-B/②)으로 가는 전이 예외 + 저장 결과 재열람 진입로가 홈에서 사라져 별도 진입로가 필요해짐.

## 재개 조건 / 착수 시 할 일

- 재진단 결과를 이전 결과와 비교 제시할 수단(예: 직전 진단 대비 약점 감소 표시)이 생겨 "재측정" 서사가 정직하게 성립할 때 재검토.
- 착수 시: ④-B 재열람 진입로 대체 설계(마이페이지류 또는 배너 2분할)를 함께 결정할 것.
