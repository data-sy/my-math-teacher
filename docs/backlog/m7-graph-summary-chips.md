# [백로그] ⑥ 그래프 — B안 "요약 칩" 오버레이 이식

> 등록 2026-07-19 · 출처 = 그래프 위계 백지 컨설팅(A안 색 층위 채택 시 B안에서 이월 지정된 항목, `docs/handoff/m7-graph-scheme-a-handoff.md` "하지 않는 것" 절)

## 무엇

노드 선택 시 캔버스 상단에 **"토대 N개 · 열리는 길 M개"** 요약 칩 오버레이 — 색 층위가 전달하는 방향·수량 정보를 텍스트로 한 번 더 요약(계보가 화면 밖으로 잘릴 때의 보완).

## 왜 지금 안 하나

- A안(색 층위) 단독으로 1탭 판독 목표 충족 여부를 먼저 사용자 테스트로 확인 — 칩은 그 결과가 부족할 때의 증강.
- 컨설팅 결정: B안 요소는 이번 범위 아님(밴드 재배치·거터 금지와 함께 명시).

## 착수 시 할 일

- 계보 카운트는 이미 구현된 방향 BFS(`ConceptGraph.tsx` `bfsDist`) 결과 재사용 — 추가 API 불요.
- 칩 탭 동작(예: 해당 방향 fit)은 정의부터 — 컨설팅 산출엔 표시만 있음.
- "한 덩어리" 문제가 사용자 테스트에서 재현되면 B안(공간 재배치) 승격 재논의가 선행 조건 (핸드오프 결정 절).
