정본 = `docs/design/v2/06-graph.html` ●4 절 + `🤖-그래프-위계-A안-핸드오프.md`. 요약:

### ⑥ 그래프 탐색 화면
- **무선택**(빈 곳 탭 후): 전 노드 중립 단일 톤(종이색 채움·회록 테두리)·균일 크기 34px, **전 노드 이름 표시**(노드 하단).
- **노드 탭 = 선택**: 그 노드 중심으로 —
  - 선택: 잉크 채움 + 흰 링 + 잉크 외곽 링 + 할로, 40px, 이름 12px 굵게
  - 선수(토대·아래로 가는 계보): 직접(거리1) = 진한 틸 `#0e7a6c` 30px / 원거리(거리2+) = 연한 틸 `#2fb5a6` 22px(뎁스3+ 18px)
  - 후수(열리는 길): 직접 = 진보라 `#7c3aed` 30px / 원거리 = 연보라 `#a78bfa` 22px
  - 계보 밖(선수도 후수도 아님): 무채색 `#dce1e8` 14px 축소, 이름 8px (오퍼시티 사용 안 함)
  - **모든 계보 내 노드는 이름 표시** — 직접 10.5px 굵게, 원거리 9px
  - 엣지: 선택 인접 = 2.5px 방향색 + 화살촉 / 계보 내 = 1.5px 틴트(`#a5d8d2` 틸측·`#d4c6fd` 보라측) + 화살촉 / 계보 밖 = 1px 무화살촉
  - 선택 노드로 250ms 센터링, 상태 전이 220ms 1회. 지속 애니메이션 없음.
- 계보 판정 = **방향 BFS**: 엣지 방향 from(선수)→to(후수) 기준, 선택에서 선수 방향으로 도달 = 토대, 후수 방향 = 열리는 길. (구 구현의 무방향 BFS depth≤2 선명/흐림과 다름 — 그건 폐기됨)

### ④-B 저장 결과의 개요 그래프 (같은 컴포넌트, `compact` 모드)
- **이름은 선택 노드만 표시** — 의도된 동작 (미선택 시 이름 0개도 정상). 축소 fit 에서 15개 라벨이 겹쳐 뭉개지는 것 방지.
- 학습 경로 노드 = 연틸 채움 + 틸 테두리(path 스타일) 유지.

## 추적 세션 착수 순서

1. **증상 수거부터**: 어느 화면(⑥/④-B)·무선택/선택 어느 상태·기대 vs 실제. "이름 안 뜸"이 ④-B였다면 그건 스펙대로임을 안내하고 UX 로 불만이면 스펙 재논의.
2. 알려진 의심 지점 (구현 세션이 남기는 힌트):
   - `compact` 모드 스타일이 `...(compact ? [...] : [])` 스프레드로 들어감 — ⑥ 에 잘못 전파되는지 확인 (⑥ 은 compact 미전달이 맞음)
   - dev HMR 중 상태 클래스 잔존 가능 — 새로고침 후 재현 여부부터
   - `breadthfirst` 레이아웃에서 노드 하단 라벨(`text-valign: bottom`)이 다음 행 노드에 가려질 수 있음 — 라벨 z-order/간격
   - 엣지 방향 실서버 실측 = source(선수)→target(후수) (`frontend-spec.md` §8) — mock 과 방향 일치 확인
