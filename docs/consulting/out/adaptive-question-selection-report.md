## ① 서베이 (계열별)

**1. KST 계열 (지식공간이론 / ALEKS)**
지식공간이론은 개념 집합의 부분집합 중 "실제로 도달 가능한 지식상태(knowledge state)"들만 모은 지식구조를 정의하고, 학생이 어느 상태에 있는지를 최소 질문으로 좁힌다. ALEKS의 핵심은 "지금 답이 지식상태 후보 집합을 절반으로 가르는(정보량 최대) 문항"을 고르는 것 — 본 서비스의 선수 DAG는 이미 "A를 알면 A의 선수 폐쇄도 안다"는 폐쇄 규칙을 내장하므로 KST의 선행/후속 폐쇄 구조와 개념적으로 **동형**이다. 즉 현행 R1(알아요→선수 폐쇄 skip)은 이미 조잡한 KST다. 개선 여지는 "다음 문항 선택을 conceptId 순 대신 후보 상태공간을 가장 크게 가르는 개념"으로 바꾸는 것 — 이건 데이터 없이 DAG 구조만으로 계산 가능(콜드스타트에 강함).

**2. CAT / IRT 계열 (최대 정보량 문항 선택)**
IRT는 문항마다 난이도·변별도 모수(a,b,c)를 추정해 두고, 현재 능력 추정치 θ에서 Fisher 정보가 최대인 문항을 고른다. 정석 CAT이지만 **모수 추정에 문항당 수백 응답이 필요** — 실사용자 0인 콜드스타트에서는 a,b를 추정할 수 없어 사실상 사용 불가다. 또 본 진단은 능력 θ 하나가 아니라 개념별 이진 상태를 다루므로 단일 잠재특성 IRT와 정합이 낮다. 다만 "개념 난이도"를 DAG 깊이(선수 사슬 길이)의 프록시로 대체하면 IRT의 정신(정보량 큰 문항 우선)만 값싸게 빌려올 수 있다. 정통 IRT 도입은 실데이터 축적 후로 미루는 게 타당.

**3. DKT 역이용 (이미 떠 있는 모델을 문항 선택에 사용)**
이미 TF Serving에 DKT가 떠 있으므로, 지금까지의 답변 시퀀스를 넣어 **아직 안 물어본 개념들의 예측 정답확률**을 받고, 그 확률이 0.5 근처(= 모델이 가장 불확실)인 개념을 다음에 묻는다. 추가 인프라 0이고 "정보량 최대" 원칙을 데이터 기반으로 구현하는 가장 직접적 방법. 다만 (a) DKT는 원래 문제풀이 정오답으로 학습됐는데 여기선 자가보고를 정오답으로 매핑하는 도메인 시프트가 있고, (b) 매 문항 선택마다 TF Serving 왕복이 생겨 stateless 순회의 지연·비용이 커지며, (c) DKT 출력이 버전/부동소수에 따라 흔들리면 **결정론 계약이 깨진다**(같은 답변→같은 다음질문 보장이 모델 출력 안정성에 종속). 결정론을 지키려면 확률을 고정 소수 자리로 양자화·tie-break 규칙 고정이 필수.

**4. 밴딧 / 탐색-활용 계열**
멀티암드 밴딧은 "정보를 얻기 위한 탐색"과 "이미 좋은 선택 활용"의 균형을 온라인으로 학습한다. Thompson sampling·UCB 등. 그러나 밴딧은 본질적으로 **누적 보상을 여러 세션에 걸쳐 학습**하는 틀 — 실사용자 0·세션 3분·stateless·결정론과 정면충돌한다(무작위 샘플링은 결정론 위반, 학습은 데이터 필요). 개별 진단 세션의 문항 선택 엔진으로는 부적합. 다만 나중에 "여러 후보 정책(A/B) 중 어느 순서 규칙이 이탈률·재방문이 좋은지"를 오프라인으로 고르는 메타 레이어로는 쓸 수 있다 — 지금은 아님.

**5. 휴리스틱 강화 (현행 규칙 + 최소 보수)**
현행 규칙을 유지하면서 세 결함에 국소 패치만 얹는 가장 싼 안: (a) **최소 질문 수 하한**과 종료 전 확인 질문 — 결함1 해소, (b) "알아요" 폐쇄에 대한 **샘플링 검증 문항**(폐쇄 전체를 믿지 말고 몇 개 재확인) — 결함2 해소, (c) 다중 선수 질문 순서를 conceptId 대신 **blockedDescendants(그 개념을 몰라요 하면 추가로 파야 할 후손 수) 내림차순** 등 구조적 정보량으로 정렬 — 결함3 해소. 전부 DAG 구조만으로 계산되어 콜드스타트·stateless·결정론과 완전 양립하고, API 계약·③ 화면 불변. 증분 구현량이 가장 작다.

## ② 후보 비교표

| 후보 | 결함1 (1문 종료) | 결함2 (폐쇄 과신) | 결함3 (순서 무근거) | stateless·결정론·3분 양립 | 콜드스타트 요구 데이터 | 구현 난이도(현행 대비 증분) | 주요 리스크 |
|---|---|---|---|---|---|---|---|
| **KST(구조 기반 정보량)** | 상태공간이 1문에 다 안 갈리면 계속 질문 → 자연 해소 | 폐쇄 skip을 "상태 좁히기"로 재해석, 부분 확인 가능 | 상태공간 이분 크기로 순서 결정(근거 있음) | 전부 양립(DAG만으로 결정론적) | 없음(구조만) | 중 — 상태공간/정보량 계산 로직 신설 | 수백 노드 상태공간 계산량, 개념 모델링 부담 |
| **CAT/IRT 정통** | 정보 소진까지 질문 → 해소 가능 | θ 추정으로 간접 완화 | Fisher 정보 순 | 결정론 OK, 모수 있으면 stateless OK | **문항당 수백 응답(치명)** | 고 — 모수추정 파이프라인 | 콜드스타트에서 사용 불가, 단일 θ 부정합 |
| **DKT 역이용** | 불확실 개념 남으면 계속 → 해소 | 폐쇄 내 개념 확률 재확인으로 강하게 완화 | 확률 0.5 근접도 = 정보량 순 | **결정론 위험(모델 출력 안정성 종속)**, 매 스텝 TF왕복 지연 | 없음(모델 기존) | 중~고 — TF 호출·양자화·tie-break | 도메인 시프트, 지연/비용, 결정론 깨짐 |
| **밴딧/탐색-활용** | 원리상 가능하나 세션 단위 부적합 | 탐색으로 완화 가능 | 학습된 가치 순 | **결정론 위반(랜덤성)·데이터 필요** | 다세션 보상 로그 | 고 | 3분·stateless·콜드스타트 전부 충돌 |
| **휴리스틱 강화** | 최소질문 하한+확인질문으로 직접 해소 | 폐쇄 샘플링 검증으로 직접 완화 | blockedDescendants/깊이 내림차순 | **전부 완전 양립** | 없음(구조만) | **저 — 현행에 국소 패치** | 하한값·샘플링율 튜닝 heuristic, 이론적 최적성 없음 |

핵심: 콜드스타트+결정론+stateless라는 3제약이 IRT·밴딧을 사실상 탈락시킨다. 살아남는 축은 **DAG 구조 정보량(휴리스틱↔KST 연속선)** 과 **DKT 역이용** 둘.

## ③ 판별 질문 (≤3)

**Q1. 결정론 계약의 엄격도 — DKT 출력을 문항 선택 루프에 넣어도 "같은 답변→같은 다음질문"을 계약으로 지킬 수 있나?**
- 절대 불변(preview=저장 결과가 법적/제품 계약, 모델 재배포로도 흔들리면 안 됨) → **DKT 역이용 탈락**, 구조 기반(휴리스틱/KST)으로.
- 양자화·tie-break로 안정화하면 허용, 모델 버전 핀 가능 → DKT 역이용 후보 유지.

**Q2. 다음 2주에 넣을 수 있는 증분의 크기 — 현행 규칙에 패치인가, 선택 엔진 재설계인가?**
- 패치 수준(런치 먼저, 최적성 나중) → **휴리스틱 강화**.
- 상태공간/정보량 엔진을 지금 세우고 싶다 → **KST 구조 기반**.

**Q3. "알아요" 오보고(과대평가 학생)로 인한 진단 오염을 얼마나 심각하게 보나?**
- 심각(오염이 학습큐 전체를 망침) → 폐쇄 샘플링 **검증 질문을 필수**로(휴리스틱 강화의 결함2 패치 강화, 또는 KST의 부분확인).
- 경미(자가진단이니 사용자 책임, 속도 우선) → 검증 질문 최소화, 3분 상한·최소질문 하한만.

매핑 요약: Q1이 DKT를 켜고 끄는 스위치, Q2가 휴리스틱↔KST를 가르고, Q3가 결함2 패치의 강도를 정한다.

## ④ 권장안 + 단계적 채택 경로

**권장: 「휴리스틱 강화」를 즉시 채택하고, 구조 기반 정보량(KST 방향)으로 점진 업그레이드. DKT 역이용은 결정론 리스크가 해소될 때만 실험 브랜치로.**

이유: 콜드스타트·stateless·결정론 3제약을 무비용으로 만족하는 축은 DAG 구조뿐이다. 휴리스틱 강화는 그 축에서 세 결함을 전부 직접 겨냥하면서 현행 API 계약·③ 화면·구현 골격을 건드리지 않는다. KST는 같은 축의 "이론적으로 더 옳은" 연장선이라 마이그레이션이 파괴적이지 않다(같은 구조 위에서 순서 규칙만 정교화). IRT·밴딧은 데이터가 쌓인 뒤의 이야기.

**단계 경로 (각 단계가 현행 R1·종료·순서 중 무엇을 바꾸는지 명시):**

- **0단계 (지금, 휴리스틱 강화 — 종료 규칙 + 순서 규칙 변경):**
  - *종료 규칙 변경*: "후보 소진 = 종료"에 **최소 질문 수 하한 K**(예 8~10)를 AND 조건으로 추가. 하한 미달이면 아직 안 물어본 개념(프론티어에서 가까운 순)을 채워 넣어 결함1 해소. 상한(3분/20문)은 유지.
  - *순서 규칙 변경*: "몰라요 시 직계 선수" 순서를 conceptId → **blockedDescendants 내림차순(동점 시 DAG 깊이, 그다음 conceptId로 tie-break)**. 정보량 큰 것부터 물어 결함3 해소, 결정론 유지.
  - R1은 이 단계에선 유지.

- **1단계 (폐쇄 검증 — R1 규칙 변경):**
  - R1 "알아요→선수 폐쇄 전체 skip"을 **"폐쇄에서 결정론적 규칙으로 샘플 k개(예 폐쇄 크기의 √n, 가장 깊은/가장 blocked 큰 노드 우선) 재확인, 샘플이 모두 알아요면 폐쇄 skip 유지, 하나라도 몰라요면 그 서브트리만 재개방"** 으로 교체. 결함2 해소. 샘플 선택이 결정론적이어야 계약 유지(랜덤 금지, 구조 순위로 고정).

- **2단계 (구조 기반 정보량 = KST 방향 — 순서 규칙 전면화):**
  - 다음 문항 선택을 국소 순위(blockedDescendants)에서 **"현재 답변과 양립하는 지식상태 후보 집합을 가장 균등하게 가르는 개념"** 이라는 전역 정보량 기준으로 승격. 여전히 DAG 구조만으로 결정론적 계산. 0·1단계의 하한/검증은 그대로 유지되며 순서 규칙만 정교해진다.

- **3단계 (실데이터 축적 후, 선택적):**
  - (a) 로그가 쌓이면 **DKT 역이용**을 실험 플래그로: 아직 안 물어본 개념 확률이 0.5 근접인 것 우선. 단 Q1이 "허용"일 때만, 확률 양자화·모델 버전 핀·tie-break 고정으로 결정론 계약을 코드로 방어. 오프라인에서 preview=저장 동치를 회귀 테스트로 강제.
  - (b) 응답이 충분히 쌓이면 개념별 "알아요 비율"을 난이도 프록시로 축적 → IRT 정신을 값싸게 근사(정통 IRT는 여전히 과함).
  - 밴딧은 세션 엔진이 아니라 **정책 A/B 메타 선택**(0/1/2단계 파라미터 K·k·순서 규칙 중 이탈률 최적 조합 고르기)에만 오프라인으로 한정 도입.

**첫 두 주 실행 핵심**: 0단계(하한 + blockedDescendants 순서)만으로 결함1·3이 닫히고, 1단계(폐쇄 샘플 검증)로 결함2가 닫힌다. 이 셋은 전부 구조 계산·결정론 유지·API 불변이므로 런치 블로커를 만들지 않는다. KST 전역 정보량(2단계)과 DKT(3단계)는 런치 후 개선 트랙으로 미룬다.

---

두 개의 열린 결정은 사용자 몫으로 남깁니다: (1) Q1 답에 따라 DKT 역이용을 3단계에 남길지 완전 배제할지, (2) Q3 답에 따라 1단계 폐쇄 검증을 런치 필수로 볼지 런치 후로 미룰지. 나머지 경로는 위 순서대로 권장합니다.
