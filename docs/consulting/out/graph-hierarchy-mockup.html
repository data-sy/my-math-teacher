개념 그래프 시각 위계 — 콘셉트 3안 비교

샘플 시나리오: 「일차방정식」 탭 직후 · 25노드 · 선수/후수 각 뎁스 3 · 측면(계보 밖) 8노드.
콘셉트 A·C는 좌표 동일(스타일 차이만), B만 공간 재배치. 캔버스 390×450 = 모바일 실측 비율.

A. 색 층위 Hue = 방향 · 명도 = 거리

위치는 그대로 — 색의 온도차 없이, 냉색 두 계열이 앞뒤를 가른다.
선택 선수·직접 선수·원거리 후수·직접 후수·원거리 계보 밖
리스크: 원거리 라이트 톤은 대비 2.4~2.6:1로 의도적 후퇴 — 라벨이 판독 보조 필수. 난색 미사용으로 경고 의미와 충돌 없음.

B. 공간 재배치 위치 = 방향 · 명도 = 거리

탭하면 그래프가 재정렬 — 토대는 위, 열리는 길은 아래, 다른 갈래는 가장자리로.
선택 직접(±1) 뎁스 2 뎁스 3 계보 밖(가장자리)
리스크: 탭마다 좌표가 바뀌어 공간 기억(지도 항상성)이 깨짐 + 전이 애니메이션 비용. 대신 "한 덩어리" 문제를 구조적으로 해소.

C. 형태·크기 채움 = 방향 · 크기·명도 = 거리

색 최소주의 — 쌓인 토대는 꽉 찬 원, 아직 안 연 것은 빈 원.
선택 선수·직접(채움) 선수·원거리 후수·직접(빈 원) 후수·원거리 계보 밖
리스크: 빈 원은 축소·저줌에서 시각 무게가 급감 — 후수 진영이 먼저 사라져 보일 수 있음. CVD·흑백 인쇄에는 가장 안전.
팔레트는 dataviz 검증기(OKLab CVD 시뮬레이션) 통과: 방향 hue 쌍 #0D9488↔#7C3AED ΔE 21.0(deutan)·원거리 쌍 13.1, 명도 램프 모노톤·스텝 간격·라이트엔드 대비 PASS. 원거리 톤의 3:1 미만 대비는 "후퇴" 목적의 의도적 WARN — 릴리프는 라벨이 담당.
