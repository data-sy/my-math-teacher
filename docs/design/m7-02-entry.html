지금 어디쯤이야?

요즘 배우는 단원이나 시작하고 싶은 데를 하나만 골라. 딱 맞을 필요 없어 — 여기서부터 훑기 시작하는 것뿐이야.

  • ↓ 이전 계단 (선수지식)
⤴ 여기 없음?

괜찮아, 다른 길도 있어

어디를 골라도 괜찮아. "몰라요"가 나오면 알아서 더 아래 계단으로 내려가 물어봐 줄게.

  • 원탭후보 버튼 탭 = 그 자리에서 ③ 진단 시작 (별도 "다음" 버튼 없음) — 화면 1차 행동 = default 후보 하나만 검은 채움
  • soft default학년 chip → 시기 추정 단원을 배지+강조로 제안만. hard auto-start 아님 (R6: 오추정은 ±후보·escape가 흡수)
  • 계단 표현들여쓰기 + ↑↓ 레일 캡션으로 선후(계단) 순서를 시각화. 후보 3~4개면 충분 ("몰라요→drill-down"이 관용 흡수)
  • escape두 갈래 필수(F-3): (a) 다른 단원 직접 선택 (b) 모르겠어→전체 훑기 — (b)가 "그냥 약점 궁금한" 유저 흡수
  • 카피"지금 어디쯤이야?" = 배울 내용이 아니라 시작점 선택. 진도 안 묶인 유저(복습·선행)도 pick+escape(b)로 흡수 — 별도 모드 UI 없음(확정)
