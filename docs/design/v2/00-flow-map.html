인터랙션 노트 (클릭 → 무슨 일이 일어나나)

1
홈의 1차 CTA는 "무료 진단 시작" 단독 압도. 그래프는 히어로 비주얼(눌러도 이동하지 않는 미끼 — 하이파이에서 미세 인터랙션 검토), "둘러보기"는 시각 무게 없는 텍스트 링크. PRD F-4 홈 입구 A안
2
진입 화면은 "무엇을 배울지"가 아니라 "지금 어디쯤이야?"(시작점)를 묻는다. default 단원은 미리 선택된 상태로 보여주되 자동 시작하지 않음(소프트). 후보를 탭하면 즉시 ③으로(별도 확인 버튼 없음 — 원탭). PRD F-3
3
escape는 반드시 두 갈래: (a) 전체 단원 목록에서 직접 선택 (b) "모르겠어 → 전체 훑기" = 학교급 대표 단원 프론티어 합집합에서 시작. (b)가 "그냥 약점 궁금한" 유저를 흡수하므로 단원 강제 선택이 되살아나지 않음. PRD F-3 · spec-01 §4.2
4
"알아요" 탭 → 그 개념의 선수 폐쇄 전체가 이후 질문에서 제외(화면 수 급감 체감의 핵심). "몰라요" 탭 → 직계 선수가 다음 질문 후보로 push(뿌리 찾기 drill-down). 서버가 매 요청 answered-map 전체로 재계산 — 클라는 순회 로직을 모름. spec-01 §4.3 D1-A
5
매 답변 직후 localStorage에 answered-map 저장. 브라우저를 닫고 돌아와도 같은 지점에서 재개, 결과-시점 로그인 때 이 맵을 그대로 재제출해 계정 귀속(서버는 익명 구간에 아무것도 저장 안 함). 이어가기 범위(확정): 같은 단원의 진행 중(미완주·미저장) 세션만 — 새 진단 시작 = 새 세션. PRD F-2 · spec-01 S1-A
6
결과 화면 레벨 1차 CTA는 "저장하고 학습 경로 시작하기" 하나뿐. 비로그인이면 이 탭이 로그인 트리거(⑤ 경유). 카드 안의 "학습 경로 보기"는 2차 스타일로 강등 — 탭하면 동일 게이트로 수렴. 무료 구간(헤드라인·카드·외부링크)만으로 "개념·순서·자료"가 충족되어야 함(런치 판정 §5.1). PRD F-1
7
로그인 성공 콜백 → 클라가 저장해둔 answered-map으로 귀속 API 호출 → 큐 생성 → ④-B로 자동 전환. preview와 귀속 결과는 동일해야 함(결정론 계약 — "본 결과가 저장됐다"는 약속). 실패 시 ⑤-B 에러 카피. spec-01 §4.1·§8
8
큐 항목 탭 → 완료 self-mark 토글(앱은 외부 학습을 검증하지 않음). 현재 위치 = 첫 미완료 항목(파생값). 재진입은 저장 큐 이어가기이고, 재진단은 별개 액션으로 ②부터 새로 — 새 큐가 활성 큐를 대체. 홈 "이어서" 배너(로그인+활성 큐 보유 시 노출) 채택 — 2026-07-17 확정. PRD F-4 재진입 · spec-01 §4.6
9
⑥은 진단과 독립 진입 가능한 무료 화면. 상시 "내 약점 진단하기" CTA로 탐색→진단 루프를 만든다. 호버 의존 0 — 모든 그래프 조작이 탭으로 가능해야 함(모바일 무결 §5.1). PRD F-4 · §3.2 ⑥
10
에러는 별도 페이지가 아니라 상황 내 표시 우선(문답 중 네트워크 실패 = 카드 자리 인라인 재시도). TF Serving 실패 시에도 "몰라요" 목록 기반 결과는 성립(fail-soft) — 시급도 등급 자리만 결측 표시. 전부 "알아요"면 카드 0장 + "약점 없음" 헤드라인 = 정상 결과. spec-01 §4.4 R2·§4.7
11
약점 0(전부 알아요) = 시작점이 너무 쉬웠다는 신호(순회는 아래로만 감) → 1차 CTA를 "한 계단 위 단원 진단하기"로 타게팅(② 계단순 pick-list 데이터 재사용). 게이트 CTA·저장 없음 — 큐는 약점 기반이라 이 경우 빈 큐. 그래프 확인은 조용한 링크 ›. 2026-07-17 A/B 비교(04-result-empty-variants.html) B안 확정
