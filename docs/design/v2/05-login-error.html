401(확정)
세션 만료 시 인라인 안내 → ⑤-A 재로그인 → 보던 화면 복귀(홈으로 튕기지 않음). 이때 ⑤-A 안심 박스 카피는 "저장된 계단은 안전해요" 변형.
403(확정)
