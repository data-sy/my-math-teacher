(전부 알아요 → 시급도 산출 생략)
1차 CTA 보존 — 모멘텀 높은 유저에게 즉시 다음 행동 제공, 제품 루프 유지
"약점 0 = 시작점이 너무 쉬웠음" 통찰을 CTA로 번역(순회는 아래로만 가므로 재시도는 위로) — F-3 스마트 default 철학과 정합
그래프 = 조용한 링크 → 홈(F-4)과 동일 패턴, 전 화면 일관
"한 계단 위" 단원 산출 로직 필요(② 계단순 정렬 재사용 — 프론트 로직, 소폭)
추천이 틀리면(이미 아는 단원) 무의미한 CTA — 탭하면 ②로 보내 pick-list에서 조정 가능하게 해 완화
B안 변형(B′): 타게팅 없이 1차 버튼 = "다른 단원 진단하기"(→ ② 진입, default 를 한 계단 위로 부스트). 화면 로직 최소화 버전 — B 채택 시 타게팅 여부만 후속 결정. · 두 안 공통: "그래프에서 확인하기"는 ›, 문답의 "이전 답 수정"은 ‹ (방향 대비).
