화면 레벨 규칙
  • 같은 화면 2상태(확정) — ④-A/④-B는 별개 페이지가 아니라 한 화면의 상태 전환. 로그인·귀속 성공 시 그 자리에서 B로 전환, 재열람(홈 배너 등) 진입 시 처음부터 B로 도착.
  • 1차 CTA는 상태당 하나: A = "저장하고 학습 경로 시작하기", B = 없음(재열람 화면 — "다시 진단하기"는 보조), 약점 0 = "한 계단 위 진단하기".
  • 내부 용어(percent, depth, probability) 화면 노출 금지 — urgency 등급·blockedDescendants 사람 언어만(§4.2).
  • preview rate limit 429 → ⑤-B 학생 친화 카피("잠깐 쉬었다 다시") — 인라인 표시, 답변 맵은 무사.
  • 무료 상태만으로 "개념·순서·자료"가 충족되어야 함(§5.1 런치 판정) — 게이트는 그래프 경로·저장·큐만.
