5
노드 정보 바텀시트 — 3열 스택 체인(확정) — 구성: 개념명 + 대표 예시(description — ③ 문답 카드와 동일 소스 D5) + 체인 "먼저(선수) → 지금 → 다음(후수)". 관계를 말로 설명하지 않고 위치와 화살표로 표현(어휘 오독 구조적 제거 — "이걸 배우려면" 문구 폐기).
체인 규칙
직계 관계만, 각 열은 세로 스택(선수·후수 여럿 = DAG를 직선으로 오해시키지 않기), 많으면 "+N". 칩은 말줄임(…) 허용 — 탭 = 그 노드로 선택 이동(●4 재포커스 + 시트 내용 교체)이라 풀네임은 이동 후 확인. 가운데 "지금"은 강조 스타일.
왜 시트인가
모바일에서 노드 옆 팝오버는 손가락에 가림 + 호버 툴팁 금지 — 하단 시트가 캔버스를 최소 침범. 닫기 = 빈 곳 탭 또는 끌어내림. 시트가 떠도 ●6 CTA는 가리지 않음.
