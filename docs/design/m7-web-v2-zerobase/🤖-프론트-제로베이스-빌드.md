# 🤖 프론트 제로베이스 빌드 — 실행 프롬프트

너의 과업: **이 리포의 기획물만으로 MMT(My Math Teacher) 프론트엔드를 백지에서 설계하고 구현한다.** 기존 구현·기존 설계는 존재하지 않는 것으로 취급한다 — 실제로 이 워크스페이스엔 없다.

## 정본 입력 (이것이 전부)

| 파일 | 역할 |
|---|---|
| `docs/design/v2/00-flow-map.html` | 화면 전이·인터랙션·**API 계약 매핑 SSOT** |
| `docs/design/v2/01-home.html` ~ `06-graph.html` | 화면별 와이어프레임(검수 확정) — 레이아웃·위계·인터랙션 노트·화면 레벨 규칙 |
| `docs/design/v2/*-variants.html`·`00-flow-map-draft.html`·`00-flow-prototype.html` | 결정 근거·리뷰 전 스냅샷(참고용) |
| `docs/prd/m7-prd.md` | 제품 요구사항 — 타깃·가치제안·화면 확정·성공 기준·비범위 |
| `docs/backend-contract.md` | 백엔드 환경 사실(서버 위치·CORS·인증 역학) — 설계 아님, 주어진 조건 |

기획물이 언급하는 그 밖의 문서(spec-01, 밀스톤, ROADMAP 등)는 여기 없다. 플로우 맵 API 표 + 접점 시트 안에서 완결하라.

## 진행 순서 (스펙 → 구현 연속)

1. **기획물 정독** — 위 정본 입력 전부. 와이어프레임의 인터랙션 노트·화면 레벨 규칙·에러 카탈로그까지가 요구사항이다.
2. **얇은 프론트 스펙 작성** — `docs/frontend-spec.md`: 스택 선정과 근거, 라우팅 구조, 상태·데이터 흐름(서버 상태/클라 상태/localStorage), 컴포넌트 구조, 에러 처리 전략. 기획물을 재서술하지 말고 **기획물에 없는 기술 결정만** 적는다.
3. **구현** — 사인오프 대기 없이 이어서 진행. 산출물 위치 = **`web-v2/`**. 작은 단위로 이 브랜치에 커밋.
4. **검증** — 6화면(④는 3상태)이 모바일 390px 뷰포트에서 기획물대로 동작하는지. 빌드 통과 + 핵심 플로우(①→②→③→④, 게이트 전환, ⑥ 탐색)를 mock 또는 실서버로 확인. 사람만 할 수 있는 검증(실 OAuth·실기기 시각검증)은 §자율주행 규율대로 종료 리포트로 이월.
5. **종료 리포트** — `docs/handoff-report.md`: 한 일 요약 · 스택 선정 요약 · 가정 로그 요약 · **사람 검증 체크리스트**(백엔드 실연동·OAuth 3사·모바일 시각검증 등) · 남은 일.

## 제약

- **프레임워크 = React** (제품 결정, 고정) + **모바일 퍼스트**(390px 기준, 데스크톱은 반응형 하한만).
- 그 외 스택(빌드체인·언어·상태관리·스타일링·라우팅·테스트)은 **네가 백지에서 선정**하고 스펙에 근거를 남겨라. 이 프로젝트 규모(6화면 MVP)에 맞는 무게로.
- 와이어프레임은 로우파이(그레이스케일) — 비주얼 폴리싱이 아니라 **레이아웃·위계·인터랙션의 충실한 구현**이 목표다. 카피는 와이어프레임 문구를 그대로 쓴다.
- 내부 용어(percent·depth·probability 등)를 화면에 노출하지 않는다 — 기획물의 표기 규율을 따른다.

## 자율주행 규율 (완주까지 무정지)

이 프롬프트는 **종료 리포트까지 자율주행**이다. 중간에 사용자 질문·승인 대기로 멈추지 않는다.

- **백엔드 도달성은 시작 시 1회만 확인** (예: `curl -s http://localhost:8080/api/v1/chapters`). 떠 있으면 실서버를 1차 소스로, 아니면 **mock 우선 모드로 전환해 끝까지 완주** — 서버 기동을 기다리거나 요청하며 멈추지 않는다. 실연동 검증은 체크리스트로 이월.
- **판단이 갈리는 지점은 더 가역적인 쪽을 택하고 계속 간다.** 선택한 가정은 `docs/assumptions.md` 에 한 줄씩 기록(무엇을 가정했나 · 근거 · 뒤집으려면 어디를 고치나). 기획물과 모순되는 가정은 금지 — 기획물이 침묵하는 지점만 가정으로 메운다.
- **사람만 할 수 있는 검증**(실 OAuth 완주·실기기 시각검증)은 시도하다 멈추지 말고 종료 리포트의 체크리스트로 이월한다.
- **완주 조건(전부 충족 시 종료):** ① `docs/frontend-spec.md` ② `web-v2/` 6화면(④ 3상태 포함) 구현 ③ 프로덕션 빌드 통과 ④ 핵심 플로우 확인(mock 가능) ⑤ 작은 단위 커밋 완료 ⑥ `docs/handoff-report.md` 작성.
