## 2. 스택 선정 요약 (근거 상세 = frontend-spec.md)

Vite + React 19 + TypeScript · react-router v7 · TanStack Query(서버 상태) · Context+localStorage(클라 상태, 라이브러리 없음) · CSS Modules(그레이스케일 토큰) · **Cytoscape.js**(기획물 명시 재사용 전제) · MSW(mock↔실서버 코드 무변경 전환) · Playwright(390px 플로우 스모크).

- mock 스위치: dev 기본 on, `VITE_ENABLE_MOCK=false` 로 실서버 전환(포트 5173 = CORS 허용 포트).
- 에러 시뮬레이션 개발 스위치: 콘솔에서 `localStorage.setItem('mmt.mockError', '429'|'400'|'failsoft'|'neterr')`.
