# m7 web-v2 제로베이스 빌드 — 근거 자산 (2026-07-17~18)

`web-v2/`가 **왜 지금 모습인지**를 남기는 폴더다. 결과물은 이미 리포에 있고(`web-v2/`),
여기 있는 건 그 결과에 이르게 한 **입력 아닌 판단 기록** — 특히 현재 쓰는 색이 왜 그 색인지다.

## 출처 (2026-08-15 이관)

원래 별도 로컬 샌드박스 `~/my-math-teacher-zerobase`(원격 없음, 브랜치 `feat/m7-web-v2-zerobase`)에 있었다.
그 샌드박스는 **이 리포를 기획물만 남기고 벗겨낸 격리 워크스페이스**였다 — 기존 프론트 구현·설계를
"존재하지 않는 것으로 취급"하고 와이어프레임·PRD만으로 프론트를 백지에서 다시 짜본 실험
(2026-07-17 23:23 ~ 07-18 16:19, 25커밋). 마지막 커밋이 스스로를 "샌드박스 역할 종료(재료 창고)"로
규정했고, 구현분은 이 리포 `web-v2/`로 이관돼 이후에도 계속 다듬어졌다.

샌드박스 자체는 원격 백업이 없어 2026-08-15에 폐기했고, **이 리포에 사본이 없던 것만** 여기로 건졌다.
`docs/design/v2/`·`docs/prd/m7-prd.md`·`docs/backlog/m7-*`는 애초에 이 리포에서 샌드박스로
복사해 간 입력이라 이관 대상이 아니었다.

## 방법론 (폴더 루트)

| 파일 | 역할 |
|---|---|
| `🤖-프론트-제로베이스-빌드.md` | 실험을 정의한 실행 프롬프트 — 정본 입력 목록, 스펙→구현 연속 진행 순서, 자율주행 규율 |
| `샌드박스-격리-규율.md` | 샌드박스의 `CLAUDE.md` 원본. *"이 리포가 세상의 전부다 — 상위 디렉토리·다른 로컬 경로·git 원격을 탐색하지 않는다"* 가 핵심 조항 |

⚠️ 격리 규율 파일은 **일부러 `CLAUDE.md`가 아닌 이름으로 옮겼다.** 그 이름 그대로 두면 이 디렉토리
스코프의 실제 지침으로 자동 로드돼, 폐기된 샌드박스 규율이 현행 작업에 발화한다. 읽는 자료이지
적용되는 규율이 아니다.

## hifi/ — 하이파이 팔레트 결정 근거

현재 web-v2가 쓰는 **C안 "틸 그로스"** 를 고른 과정이다. A안은 초기에 폐기, B/C를 블라인드로 붙였다.

| 파일 | 역할 |
|---|---|
| `hifi-direction-candidates.html` | 방향 후보 3안 제시 (A 폐기 후 B·C가 남음) |
| `hifi-blind-1.html` / `-2.html` | 블라인드 시안 — 레이아웃·카피·컴포넌트 동일, **색 팔레트만 다름**. 라벨(가/나) 순서를 뒤집은 2벌로 순서 효과 상쇄 |
| `🤖-하이파이-BC-블라인드-평가-프롬프트.md` | 격리 세션용 프롬프트 8종 = 전문가 페르소나 4 × 순서형 2. 판정 기준은 **클릭 유발·유입/가입** 단일 축. 맨 아래 「판독 키」로 가/나 → B/C 환산 |
| `eval-results/` | 평가 결과 |

**판독 키**: 순서형 ①(프롬프트 1·3·5·7) = 가:B안 딥블루 / 나:C안 틸 · 순서형 ②(2·4·6·8) = 뒤집힘.

⚠️ **정직한 갭**: 설계는 8세션인데 **저장된 결과는 1건**(`blind-s3-z세대-디자이너.md`, 순서형 ①)이다.
나머지 세션이 실행되고 기록만 안 남은 건지, 애초에 1건으로 끊고 사람이 확정한 건지는 불명 —
커밋 메시지는 "블라인드 평가+사용자 확정"이라고만 적혀 있다. 결론 재검토 시 이 점을 감안할 것.

저장된 1건의 논지: 유입 경로가 학생 커뮤니티·SNS 또래 확산이라면 병목은 신뢰가 아니라
**광고 필터 통과**다. 네이비+코발트는 인강·재수학원 배너의 색 문법이라 반사적으로 걸러지고,
틸은 그 데이터베이스에 없다 → **나(C안 틸)**.
