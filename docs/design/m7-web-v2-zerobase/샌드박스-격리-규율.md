# MMT 프론트 v2 — 제로베이스 샌드박스

이 워크스페이스는 **MMT(My Math Teacher) 프론트엔드를 기획물만으로 백지에서 설계·구현하는 격리 샌드박스**다.

- 시작 방법: [`🤖-프론트-제로베이스-빌드.md`](🤖-프론트-제로베이스-빌드.md) 를 읽고 그대로 실행한다.
- 기획물 정본 = `docs/design/v2/`(플로우 맵 + 화면별 와이어프레임) + `docs/prd/m7-prd.md`.
- 백엔드 환경 사실 = `docs/backend-contract.md` (설계가 아니라 이미 존재하는 서버의 접점 사실).
- 산출물 위치 = `web-v2/` (새 디렉토리).

## 격리 규율

- **이 리포가 세상의 전부다.** 상위 디렉토리·다른 로컬 경로·git 원격을 탐색하지 않는다.
- 기획물이 언급하는 다른 문서(spec-01, 밀스톤, ROADMAP 등)는 여기 존재하지 않는다 — 플로우 맵의 API 계약 표 + 접점 시트가 백엔드 계약의 전부이며, 그 안에서 완결한다.
- 부족한 계약·사실은 실서버 호출로 확인하고, 확인 불가면 가역적 가정 + `docs/assumptions.md` 기록으로 진행한다(🤖 프롬프트 §자율주행 규율). 추측을 사실처럼 적지 않는다.
- 이 샌드박스의 실행은 **완주까지 자율주행**이 기본 — 중간에 사용자 질문·승인 대기로 멈추지 않는다.
